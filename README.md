# EasyFunCoding Website Revamp Project
A moderen, engaging redesign of the original https://easyfuncoding.com/ website, built to improve clarity, usability, and visual appeal for parents and students exploring coding classes.

## Project Overview 
EasyFunCoding is a platform offering fun, accessible coding classes for childeren of all ages. This repository is very new. Alot more to come. It contains the new, improved verison of the website - rebuilt for better structure, reabability, and maintainability.

### The goal of this revamp is to:
    - Modernize the UI/UX
    - Improve content clarify
    - Stregthen branding
    - Make the site easier to update
    - Prepare for future expanison (courses,      scheduling, payments, etc.)
